# WebInterface Projects

## About

This repository contains my Web Interface Development projects, organized into five units. Each unit includes two projects developed as part of my learning and practical work.

## Projects

### Unit 1

1. **Counter App** – A simple application to increment, decrement, and reset a counter.
2. **Student Profile Card** – Displays student details in a profile card.

### Unit 2

1. **Hobbies Card** – Displays hobbies using cards.
2. **Student Dashboard** – A dashboard to display student-related information.

### Unit 3

1. **Attendance Tracker App** – Tracks student attendance and displays attendance details.
2. **Counter App** – A counter application with interactive controls.

### Unit 4

1. **Form Validation** – Validates user input before form submission.
2. **Portfolio** – A personal portfolio website to showcase profile, skills, and projects.

### Unit 5

1. **Student Report Card** – Displays student marks and academic performance.
2. **To-Do List** – An application to add and manage daily tasks.

## Technologies Used

* HTML
* CSS
* JavaScript
* React
* Vite

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/subhalakshmi-28/WebInterface.git
   ```

2. Open the required unit and project folder.

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
